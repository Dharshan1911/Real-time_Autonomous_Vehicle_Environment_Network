# RAVEN Datasets

This directory structure organizes data used for training and evaluating the RAVEN system. 
Large generated datasets and external third-party datasets are ignored by `.gitignore` to keep the repository clean.

## Structure

- `synthetic/`: Contains `.csv` files generated by the `SyntheticTelemetryEngine` (e.g., via `scripts/generate_all.ps1`). These represent the simulated vehicle telemetry data.
- `processed/`: Intermediate processed data formats, such as windowed subsets, `NumPy` `.npy` caches, etc.
- `external/`: External third-party datasets. 

## UCI HAR (Auxiliary Dataset)

By default, the RAVEN project scripts expect the **UCI Human Activity Recognition** dataset to be placed at the repository root (`/UCI-HAR_Dataset`). Alternatively, you can place it in `data/external/` and set the environment variable:

```bash
export RAVEN_UCI_HAR_PATH=/path/to/RAVEN/data/external/UCI-HAR_Dataset
```

**IMPORTANT:** UCI HAR is an *auxiliary* dataset used solely for architectural exploration (validating the 1D CNN's capability to learn kinetic shapes from 50Hz IMU data). **It is NOT the primary RAVEN vehicle-fault dataset, and no metrics from UCI HAR are reported in the final evaluation.**
